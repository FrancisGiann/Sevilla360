# Homepage Catalog Polish

## Changes Made
- Unified the catalog layouts into a single, cohesive, bespoke editorial layout (large 82% width imagery with overlapping text cards) across Event Halls, Hotel Rooms, and Resort Villas.
- Updated the "View details" catalog button to a prominent, high-contrast dark outline that fills on hover, ensuring clear affordance (nobody has to guess what's clickable).
- Fixed the mobile modal layout by scaling down the hero gallery, providing space for the text and ensuring the "Continue Booking" action remains sticky and visible at the bottom of the viewport.
- Removed arbitrary responsive layout overrides that caused jittering between categories.
