# Receptionist ambience

`receptionist-ambience.wav` is an original locally generated neutral resort
ambience for the optional receptionist sound toggle. It is an 18-second,
mono pink-noise texture filtered to an airy 900–6200 Hz range and gently
modulated/faded with FFmpeg. It contains no music, speech, samples, or
external recording and avoids a sustained low-frequency drone. The UI only
loads it after an explicit user gesture and fades playback to a low 0.14
volume target.
